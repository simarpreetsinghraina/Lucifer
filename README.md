
# LUCIFER

A modular personal AI desktop assistant for Windows.

## Vision

LUCIFER aims to provide natural voice and text conversations,
persistent memory, intelligent assistance, internet access,
and controlled computer automation.

## Technology Stack

- Python 3.13
- PySide6 — desktop interface (planned)
- Ollama — local AI runtime (planned)
- SQLite — persistent storage (planned)

## Development Setup

### Create a virtual environment

```powershell
python3.13 -m venv .venv
```

### Activate it

```powershell
.\.venv\Scripts\Activate.ps1
```

### Install dependencies

```powershell
python -m pip install -r requirements.txt
```
